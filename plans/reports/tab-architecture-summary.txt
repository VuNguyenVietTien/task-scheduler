NAVIGATION FLOW:

URL: /projects/123?tab=kanban
  ↓
useSearchParams() extracts "kanban"
  ↓
ProjectPageWrapper receives tab: "kanban"
  ↓
ProjectPage receives initialTab: "kanban" prop
  ↓
ProjectDetailView receives initialTab: "kanban"
  ↓
useState<ViewType>(toViewType("kanban")) → "kanban"
  ↓
useEffect syncs if URL changes
  ↓
{activeView === 'kanban' && <KanbanBoard ... />}
  ↓
KanbanBoard renders with Redux tasks data

TYPE SYSTEM:

Project Views:
  type ViewType = 'list' | 'kanban' | 'gantt' | 'members' | 'report'
  const VALID_VIEWS: ViewType[] = ['list', 'kanban', 'gantt', 'members', 'report']

Tab Validation:
  function toViewType(tab?: string): ViewType {
    return VALID_VIEWS.includes(tab as ViewType) ? (tab as ViewType) : 'list'
  }
